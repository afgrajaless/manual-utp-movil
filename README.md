# Manual de usuario · UTP Móvil v02

Manual por módulos de la aplicación UTP Móvil (Universidad Tecnológica de Pereira): pantalla por pantalla, con recuadros numerados y la explicación de cada elemento.

Sitio estático (HTML + imágenes WebP), sin dependencias ni PDF, pensado para abrirse dentro del webview de la app en Android e iOS.

- Índice: `index.html`
- Un archivo HTML por módulo, en la raíz
- Imágenes en `img/`
